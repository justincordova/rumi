# Rumi — Demo Video Script (~60s)

**Goal:** Show off real-time multiplayer collaboration as the hero moment — two
cursors, one document, instant sync.

**Workflow:** Record screens in [Cap](https://cap.so) (auto-zoom + animated
cursor). Generate voiceover in [ElevenLabs](https://elevenlabs.io) from the VO
lines below. Assemble in CapCut.

**Legend:**
- **[SCREEN]** — what to do / record in Cap
- **VO** — voiceover line (paste into ElevenLabs)

---

## 1. Cold open — 0:00–0:06

**[SCREEN]** Rumi landing page, then click "Sign in" → land on the dashboard.

**VO:** "Most docs tools make you choose: write code, or collaborate. Rumi does
both — in real time."

## 2. Create a room — 0:06–0:14

**[SCREEN]** Click "Create room." Room opens with the Welcome tab. Slow,
deliberate click on the tab.

**VO:** "Spin up a room in one click. Every room is a shared, live workspace —
no setup, no merge conflicts."

## 3. The editor — 0:14–0:24

**[SCREEN]** Type in the markdown tab. Toggle the view-mode button:
split → rendered → source. Let the preview render.

**VO:** "Write in markdown with a live preview, or switch any tab to code with
full syntax highlighting across a hundred-plus languages."

## 4. Add a code tab — 0:24–0:32

**[SCREEN]** Click "+", add a tab, pick a language. Type a few lines of code —
watch it highlight.

**VO:** "Need a code scratchpad? Add a tab, pick your language, and start typing.
It's all synced instantly."

## 5. The money shot — multiplayer — 0:32–0:46

**[SCREEN]** Open the same room in a second browser window side-by-side (or split
screen). Type in one — show it appear in the other in real time. Show both
presence avatars in the top bar.

**VO:** "Here's where Rumi shines. Invite your team, and everyone edits
together — live. Every keystroke, every change, synced in under a fifth of a
second."

## 6. Drawing board — 0:46–0:54

**[SCREEN]** Add a drawing tab. Sketch a quick box-and-arrow diagram. If you can,
show it syncing in the second window too.

**VO:** "And it's not just text. Drop in a collaborative whiteboard to sketch out
ideas together, on the same canvas."

## 7. Close — 0:54–1:00

**[SCREEN]** Zoom back out to the full room with both tabs and presence avatars
visible. End on the Rumi logo / landing page.

**VO:** "Code, write, and draw — together, in real time. That's Rumi."

---

## Recording tips for Cap

- **Click deliberately and pause.** Cap's auto-zoom triggers on clicks, so slow,
  intentional clicks = clean zooms. Don't rush.
- **Record the multiplayer shot last and carefully.** It's the centerpiece. Two
  windows, type slowly in one, let the sync land visibly.
- **Record silent**, then drop the ElevenLabs VO over it in CapCut and trim to
  match. Don't narrate live.
- Total VO is ~110 words ≈ 55–60s at a natural pace. ElevenLabs free tier
  handles this easily.
